# Language-as-Being

> A theoretical framework exploring how humans understand and construct the self through text.

## ✨ What is This?

**Language-as-Being** (文本存在论) is an academic research project that develops a comprehensive theoretical framework for understanding the relationship between text, language, and self-identity.

**Core Thesis:** Language is not merely an external carrier of thought—it is an intrinsic component of cognitive activity. Text is not an indirect reflection of the self, but a direct manifestation of self in language.

## 🎯 Key Highlights

- 📚 **Interdisciplinary Framework** — Integrates cognitive linguistics, narrative psychology, stylometry, and philosophy of language
- 🔬 **Five-Dimensional Model** — A systematic approach to analyzing text-self relationships
- 🌏 **Cross-Cultural Perspective** — Bridges Western academic traditions with Chinese classical poetics (气韵)
- 🤝 **Human-AI Collaboration** — Developed through collaborative research between human researcher and AI

## 📖 The Five-Dimensional Network Model

The framework proposes five interconnected dimensions for understanding how self manifests in text:

| Dimension | Focus |
|-----------|-------|
| **Language Surface** (语言表层) | Vocabulary, syntax, punctuation |
| **Structure & Rhythm** (结构节奏) | Text organization, information density |
| **Voice & Stance** (声音姿态) | Narrative attitude, reader relationship |
| **Cognitive-Linguistic Core** (认知-语言核心) | Metaphor systems, thought patterns |
| **Existential Orientation** (存在取向) | Values, ontological stance |

These dimensions form a network rather than a hierarchy—they mutually influence each other through circular causality.

## 📚 Theoretical Foundations

This framework draws from:

- **Cognitive Linguistics** — Lakoff & Johnson's conceptual metaphor theory
- **Narrative Psychology** — McAdams & McLean's narrative identity research
- **Stylometry** — Computational approaches to authorship and style (Stamatatos, Eder)
- **Philosophy of Language** — Heidegger, Wittgenstein
- **Chinese Classical Poetics** — 气韵 (Qi-Yun) traditions
