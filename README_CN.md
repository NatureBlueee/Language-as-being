# 文本存在论

> 一套关于"人如何通过文本认识和建构自我"的理论体系

## ✨ 这是什么？

**文本存在论**（Language-as-Being）是一个学术研究项目，旨在建立一套系统的理论框架，探索文本、语言与自我认同之间的深层关系。

**核心命题：** 语言不只是思想的外在载体，而是认知活动的内在组成部分。文本不是自我的间接反映，而是自我在语言中的直接显现。

## 🎯 核心亮点

- 📚 **跨学科整合** — 融合认知语言学、叙事心理学、计量文体学与语言哲学
- 🔬 **五面向网络模型** — 系统化的文本-自我分析框架
- 🌏 **中西融通** — 连接西方学术传统与中国古典文论（气韵）
- 🤝 **人机协作研究** — 人类研究者与AI的深度学术合作

## 📖 五面向网络模型

本框架提出五个相互关联的维度，用于理解自我如何在文本中显现：

```
              【情境】
           （在什么情况下）
                 │
    ┌────────────┼────────────┐
    │            ↓            │
    │   ┌─────────────────┐   │
    │   │  认知-语言核心   │   │
    │   │  （隐喻·意象）  │   │
    │   └────────┬────────┘   │
    │            │            │
    │     ┌──────┴──────┐     │
    │     ↓             ↓     │
    │  ┌──────┐    ┌──────┐  │
    │  │ 声音 │ ←→ │ 结构 │  │
    │  │ 姿态 │    │ 节奏 │  │
    │  └──┬───┘    └──┬───┘  │
    │     └─────┬─────┘      │
    │           ↓            │
    │    ┌───────────┐       │
    │    │ 语言表层  │       │
    │    └───────────┘       │
    └────────────────────────┘
              ↓
         【自我画像】
```

| 面向 | 核心问题 | 观察内容 |
|------|----------|----------|
| **语言表层** | 你用什么词、什么句式？ | 词汇、句法、标点、段落 |
| **结构节奏** | 你如何组织、如何呼吸？ | 展开方式、节奏模式、开头结尾 |
| **声音姿态** | "谁"在说话？什么语气？ | 距离感、确定性、与读者关系 |
| **认知-语言核心** | 你用什么理解什么？ | 隐喻系统、核心意象、思维习惯 |
| **存在取向** | 你如何面对存在？ | 价值取向、本体论立场 |

这些面向构成网络而非层级——它们通过循环因果相互影响。

## 📚 理论基础

本框架建立在以下学术传统之上：

- **认知语言学** — Lakoff & Johnson 的概念隐喻理论
- **叙事心理学** — McAdams & McLean 的叙事身份研究
- **计量文体学** — Stamatatos, Eder 等的风格分析方法
- **语言哲学** — 海德格尔、维特根斯坦
- **中国古典文论** — 气韵、文如其人传统

## 🎓 核心洞见

> "认识你自己"——这是人类最古老的追问。
>
> 我们用了很多方式：内省、冥想、宗教、哲学、心理学……
>
> 现在，我们有了一种新的可能：通过我们自己产出的文本，来认识和探索自我。

这不是"技术的进步"那么简单。这是一种新的自我关系的可能——通过自己的语言痕迹，看到自己没看到的东西，探索自己没探索的角落。
