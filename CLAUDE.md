## Project Overview

This is an academic research project developing **文本存在论** (Text-Being Theory / Ontology of Text) - a theoretical framework exploring how humans understand and construct the self through text analysis.

**Core thesis:** Language is not merely an external carrier of thought, but an intrinsic component of cognitive activity. Text is not an indirect reflection of the self, but a direct manifestation of self in language.

This is a **research/writing project**, not a software project. There are no build systems, test suites, or CI/CD pipelines.

## Theoretical Framework

The project presents a **Five-Dimensional Network Model** for text-self analysis:

1. **语言表层** (Language Surface) - Vocabulary, syntax, punctuation
2. **结构节奏** (Structure & Rhythm) - Text organization, information density
3. **声音姿态** (Voice & Stance) - Narrative attitude, reader relationship
4. **认知-语言核心** (Cognitive-Linguistic Core) - Metaphor systems, thought patterns
5. **存在取向** (Existential Orientation) - Values, ontological stance

**Key theoretical sources:** Cognitive Linguistics (Lakoff & Johnson), Narrative Psychology (McAdams, McLean), Stylometry (Stamatatos, Eder), Philosophy of Language (Heidegger, Wittgenstein), Chinese Classical Poetics (气韵/Qi-Yun traditions).
